# Secure Protocols and Network Security Technologies

## Secure Protocol Design

Prefer authenticated and encrypted protocols when protecting sensitive information. TLS protects application communications; SSH provides secure remote administration; IPsec can protect IP communications and VPN tunnels; secure wireless protocols protect wireless access.

## Network Security Technologies

Firewalls enforce traffic policy. IDS detects suspicious activity and generates alerts. IPS can actively block or prevent detected traffic. Proxies mediate requests and can provide filtering and inspection. WAFs protect web applications from application-layer attacks. NAC controls network access based on identity, device state, or policy.

## VPN

A VPN creates a protected communication channel across an untrusted network. Site-to-site VPNs connect networks, while remote-access VPNs connect individual users or devices.

## Exam Focus

Choose controls according to the requirement: WAF for web application traffic, NAC for controlling endpoint network admission, firewall for network traffic policy, IDS for detection, IPS for prevention, and VPN for protected communications over untrusted networks.
