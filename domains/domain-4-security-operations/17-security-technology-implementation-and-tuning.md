# Security Technology Implementation and Tuning

## Deployment

Security technologies must be configured according to business requirements, network architecture, risk, and approved baselines. Incorrect deployment can create gaps, excessive alerts, or operational outages.

## Tuning

Security tools should be tuned using observed environment behavior. Detection thresholds that are too sensitive create excessive false positives; thresholds that are too permissive can miss malicious activity.

## Firewall and IDS/IPS Tuning

Review rules regularly, remove obsolete entries, document exceptions, and ensure rule order and scope produce the intended behavior.

## EDR/XDR Tuning

Endpoint and cross-domain detections should account for normal administrative tools, approved applications, and legitimate automation while maintaining visibility into suspicious behavior.

## Email and Web Security

Filtering systems should detect malicious attachments, suspicious links, impersonation, and abnormal content while minimizing disruption to legitimate communications.

## Exam Focus

Security technology requires continuous maintenance. A tool that is installed but poorly configured, unmonitored, or generating unmanageable alert volumes does not provide effective security.
