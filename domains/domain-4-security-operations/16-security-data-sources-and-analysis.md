# Security Data Sources and Analysis

## Endpoint Data

Endpoint telemetry can include process activity, authentication events, file changes, registry or configuration changes, security-control alerts, and network connections.

## Network Data

Network telemetry includes packet captures, flow records, firewall events, DNS logs, proxy logs, VPN logs, and wireless events.

## Application and Identity Data

Application logs reveal authentication, authorization, errors, transactions, and administrative activity. Identity systems provide login, MFA, privilege, group membership, and account lifecycle events.

## Cloud Data

Cloud audit logs can record API calls, configuration changes, resource creation, identity activity, and access to cloud services.

## Analysis

Analysts establish timelines, correlate events across sources, compare behavior against baselines, identify affected assets, and distinguish indicators from confirmed findings.

## Exam Focus

No single telemetry source provides complete visibility. Effective investigation correlates endpoint, network, identity, application, and cloud data.
