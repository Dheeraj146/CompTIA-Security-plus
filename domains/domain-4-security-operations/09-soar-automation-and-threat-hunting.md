# SOAR, Automation, and Threat Hunting

## SOAR

Security Orchestration, Automation, and Response platforms connect security tools and execute repeatable workflows. A playbook can enrich an alert, query additional sources, isolate an endpoint, create a ticket, and notify responders according to approved policy.

## Automation

Automation reduces repetitive analyst work and improves consistency. It should include safeguards, logging, authorization, error handling, and human approval for high-impact actions.

## Threat Hunting

Threat hunting is a proactive search for evidence of malicious or suspicious activity that may have escaped existing detections. Hunters use hypotheses, telemetry, threat intelligence, behavioral patterns, and environmental knowledge.

## Detection Engineering

Detection rules should be based on meaningful indicators or behaviors and continuously tuned to reduce false positives while preserving useful detection coverage.

## Exam Focus

SIEM primarily centralizes and correlates security data. SOAR orchestrates and automates response workflows. Threat hunting proactively searches for threats rather than waiting for an alert.
