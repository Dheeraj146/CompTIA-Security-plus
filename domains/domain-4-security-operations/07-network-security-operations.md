# Network Security Operations

## Firewalls

Firewalls enforce traffic rules based on addresses, ports, applications, identities, or other attributes depending on capability. Rules should follow least privilege and be reviewed for unnecessary exposure.

## IDS and IPS

An IDS detects and alerts on suspicious activity. An IPS operates inline and can block or modify traffic according to detection policy.

## Proxies and Secure Gateways

Proxies mediate communications and can enforce content, destination, authentication, and inspection policies. Secure web and email gateways can identify malicious content and suspicious destinations.

## NAC

Network Access Control evaluates devices or users before granting network access. It can enforce requirements such as device identity, authentication, and security posture.

## Network Monitoring

Monitor network flows, DNS activity, authentication events, firewall logs, VPN connections, and unusual traffic patterns. Baselines help distinguish normal behavior from anomalies.

## Exam Focus

Know where the control operates and what it does: firewall controls traffic, IDS detects, IPS prevents, proxy mediates, and NAC controls network admission.
