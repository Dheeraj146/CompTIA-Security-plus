# Endpoint, Mobile, and Application Security Operations

## Endpoint Security

Endpoints should use secure configurations, host firewalls, anti-malware or EDR capabilities, patch management, encryption, application controls, least privilege, and centralized monitoring.

## EDR

Endpoint Detection and Response collects endpoint telemetry, detects suspicious behavior, supports investigation, and can enable containment actions. XDR extends correlation across multiple security domains such as endpoints, identity, email, and network telemetry.

## Mobile Security

Mobile security operations include device enrollment, policy enforcement, encryption, screen-lock requirements, application control, remote wipe, certificate management, and separation of corporate data.

## Application Security Operations

Operational application security includes secure deployment, patching, dependency management, secrets protection, logging, access control, vulnerability remediation, and monitoring for abnormal behavior.

## Application Allowlisting

Allowlisting restricts execution to approved applications or software sources. It can be particularly valuable for tightly controlled systems but requires maintenance as legitimate software changes.

## Exam Focus

EDR is endpoint-focused detection and response. XDR correlates telemetry across multiple security domains. MDM/UEM controls managed mobile devices and their configurations.
